Machine Learning শেখার শেষ লক্ষ্য হলো project বানানো।

## Beginner project

- Titanic survival prediction
- house price prediction
- spam classifier
- customer segmentation
- handwritten digit classification

## Project workflow

1. problem define করুন
2. dataset collect করুন
3. cleaning করুন
4. baseline বানান
5. metric measure করুন
6. improve করুন
7. result explain করুন

## Portfolio tips

- notebook clean রাখুন
- result chart ব্যবহার করুন
- README লিখুন
- assumptions note করুন

## Learning roadmap

### Phase 1

- Python

### Phase 2

- regression

### Phase 3

## Best habit

একেকটা topic শেখার পর একটা ছোট project finish করুন। সেখান থেকেই real skill তৈরি হয়।
