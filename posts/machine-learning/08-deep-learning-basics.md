Deep learning হলো ML-এর এক advanced branch, যেখানে neural network ব্যবহার হয়।

## কবে দরকার

- image processing
- speech recognition
- NLP
- complex pattern learning

## Neural network কী

একাধিক layer দিয়ে data transform করা হয়।

Basic flow:

```text
Input -> Hidden layer -> Hidden layer -> Output
```

## Important terms

- neuron
- weight
- bias
- activation function
- loss function
- backpropagation

## Activation function

Activation model-কে non-linear behavior দেয়।

Common example:

- ReLU
- sigmoid
- tanh

## শুরুতে কীভাবে শিখবেন

আগে small neural network concept বুঝুন, তারপর framework ব্যবহার করুন।

## Warning

Deep learning powerful, কিন্তু data, compute, এবং tuning বেশি লাগে। সব project-এর জন্য এটা first choice না।
